# Beer Style Guidelines

Beer Style Guidelines helps beer judges and homebrewers reference beer, cider, and mead styles on iPhone, iPad, and Mac.

- [App website](https://www.beerstyleguidelines.app)
- [Release notes](https://blog.beerstyleguidelines.app)
- [Report a bug or request a feature](https://github.com/Beer-Style-Guidelines/beer-styles-feedback/issues/new/choose)
- [Browse public feedback](https://github.com/Beer-Style-Guidelines/beer-styles-feedback)

The app source code is private. The feedback repository is public: please do not post personal email addresses, other personal information, or private diagnostics. For private support, use the [contact page](https://www.beerstyleguidelines.app/contact/).
